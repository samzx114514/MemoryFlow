# LC-Sent-15-v1 Baseline Core V1

This immutable package contains only the Train/Dev `single_positive_15` track and referenced-only source catalogs. Labels are `silver_longcite`, not human Gold. Each target has exactly 15 same-document candidates: one cited official sentence unit and 14 deterministic uncited negatives.

Excluded: multi-positive sidecar, Reserve, official raw data, split assignments, models, caches, old processed data, and mixed catalogs. Text is retained exactly from Build V1. No candidate was changed or filtered.
