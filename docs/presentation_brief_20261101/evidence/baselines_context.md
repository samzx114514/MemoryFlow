# GenMem 多轨迹基线与八方法主表（2026-10-28）

一句话：在已冻结的**原窗口候选**与用户确认的 **contextual64_v4 证据**上补齐了随机、Qwen F_mean、R-SYM、D-Full-64、
CLM 五个新方法，连同既有固定头、平均头、8 个随机头与 BM25 一起，在 **47 个评测目标**上给出完整组找齐率与证据片段指标。
主结果：**固定头 @5 0.5957 / @10 0.7021，D-Full 紧随（0.5319 / 0.6809），R-SYM 0.4468 / 0.5816，BM25 0.5532 / 0.6170，
Qwen F_mean 0.2766 / 0.4043，CLM 0.1277 / 0.1915，随机 0.0108 / 0.0215**。还缺：无独立训练数据，CLM 只有官方头迁移。

## 协议与分母

| 项 | 值 |
|---|---|
| 答案 | `contextual64_v4/ground_truth.json` 的 `self_contained_evidence`（组间 OR、组内 bundle/fragment 全 AND） |
| 候选 | 冻结的**原窗口候选**（与 `scores_full.jsonl` 完全一致，未重排、未删、未复制细粒度分数） |
| 目标 | 55（v4 64 ∩ 可运行 88 = 56，排除 case_10 T01）；评测 **47**、开发 **8** |
| 组与片段 | 83 个完整 OR 组、160 个证据片段 |
| 覆盖 | 47/64 = 73%（v4）；47/88 = 53%（可运行）；8 个 v4 目标超限未跑，T01 单列 |
| 主指标 | CompleteGroup@5/@10；辅助 EvidenceFragmentHit@1/@5、KnownFragmentMRR、KnownFragmentRecall@5 |
| 随机 | 同一候选集、同一种子 `20261026`、每个目标 2,000 次均匀随机排列，取同一评价函数均值 |
| 同分 | `stable_tolerance_ranking(1e-6)` |

片段覆盖判据：窗口并集（同一 artifact）必须包含片段**全部非空白字符**；仅相交不算覆盖；等价出现只按标注计一次。

## 方法来源与输入形式（一句话）

- **固定头 (19,15)**：冻结 Qwen2.5-7B-Instruct 的 19 层 15 头注意力，目标回放读预测行；本仓库预测，无训练。
- **BM25**：`mixed_v1_tokenize`、k1=1.2/b=0.75，每目标独立成组；CPU 词面检索，无训练。
- **平均头**：零基 20–27 层全部头平均，同一前向；消融用，无训练。
- **Qwen F_mean cosine**：Qwen2.5-7B 末层 hidden 的 attention-mask 均值、L2 归一化一次、点积；表示模型无任务训练。
- **R-SYM / D-Full-64**：LC-Sent-15 上训练的对称/方向关系头（各 3 个 seed），输入 `[t*s, |t-s|, cos]`；**跨任务迁移**，不是在 GenMem 上训练。
- **CLM**：作者 Qwen3-8B + 官方投影头 + 官方 Engine，候选集 softmax；**零额外训练的任务迁移**，不是本项目训练结果。
- **随机**：同一候选集均匀排列，2,000 次模拟，机会水平参考。

## 覆盖率与缺口

- cosine / R-SYM / D-Full / CLM 都在全部 **55** 个目标上完成（36,584 个候选对），**没有方法因长度失败**；
  主表与逐轨迹表用同一分母，未出现“不同方法用不同分母”。
- 8 个 v4 目标因原窗口候选总长超过 32,768 未跑（逐条列在 `metrics_v2.json` 的 `coverage`）；case_10 T01 因
  `needs_review` 单列，不进主指标。
- CLM 的低分对应“官方头直接迁移”；**不能写成“CLM 因为没训练所以差”**，也不代表该路线的最优可达效果。
