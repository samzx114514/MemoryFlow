# 下一阶段值得讨论的问题

用户将重新考虑研究方向。下列问题用于讨论，不是自动执行路线。

1. **目标究竟是语义支持、运行中实际使用，还是因果影响？** LC-Sent-15 支持第一项；真实运行轨迹和干预证据仍缺。若以信息流为核心，评价标签必须相应升级。
2. **需要怎样的真实 Agent 数据契约？** 旧 SP 日志保留工作流，却没有可直接恢复的语义 Gold。是否先做一个查询的完整 Source/Researcher Summary/Reporter trace，并只对有显式 ID 的边计分？
3. **现有方法迁移后还有多大价值？** Synthetic Track A 的 BM25 已达 0.9416；Track B 无 Gold。真实 Summary 的改写和多源融合可能重新改变方法排序，目前没有实测。
4. **方向性如何被真正验证？** D-Full 的 Dev 点估计高于 R-SYM，但差异和 Train–Dev gap 不支持“已经学会方向”的断言。角色交换、可见性限制或时间约束能否提供更强检验？
5. **是否继续以 LC-Sent-15 为主基准？** 它提供干净、可复现的对照，但部分负例是排版碎片，且与 Agent 信息流有域差异。后续可以保留为回归测试而调整主证据来源。
6. **艺峰方法如何公平比较？** 其原方法在生成时按 clause 聚合 Attention；当前缺固定 head 和“给定既有 Target”评分定义。拿到方法契约后应决定比较的任务是否一致。
7. **结果能否对外分享？** 仓库是私有整理。数据示例、第三方论文与 supplementary、模型和代码的发布权限需单独确认。
