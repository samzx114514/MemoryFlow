# SP1 有界运行记录器

`runner.py` 是 2026-10-16 运行记录器的保留版本，仅将后续输出位置统一到 243 的 `memoryflow/runs/sp1/`。服务器对应 `memoryflow/scripts/sp1_20261016/sp1_bounded_run_v3.py`。本次未运行这个新版，也未新增模型调用。

它保存模型输入、返回、实际 HTTP 请求、搜索返回和工作流更新，用来离线核对信息可见性，不产生语义依赖 Gold。

**已知限制：不能直接拿它重跑保险长任务。** 原版的预算异常被旧异步模型调用链误当成正常返回，SP1 又将研究失败重新委派，最终触及搜索预算。新版只调整目录，没有修复这条异常传播链。下一次真实运行前，应先用不联网的测试确认预算触发后整个任务能够立即终止，再确定子任务规模与费用上限。

依赖服务器既有 SP1.0 专用环境和私有配置。不要把配置、凭据或原始模型输入输出提交到 Git。`runner.py` 的运行模式和预算参数见文件本身；本说明不授权任何付费调用。
