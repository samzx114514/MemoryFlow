## 实现与核对

`provenance_v2/compact_query.py` 合并重复的调用片段，缓存局部归约及不同剩余深度的根分数。仍按原权重逐跳相乘、同一原文的全部路径相加。返回完整连接图和每个原文的一条代表路径；全部组合路径另作精确计数。超时或超预算明确标记未完成，不使用部分分数。

16题的缓存作者版逐题复现原版排名、路径计数和分数，最大分数差8.68e-19。另在固定开发集中最早的目标，用旧枚举实现核对前5、前10两种展开，前10原文分数最大差1.39e-17、Top10一致。共享上游、歧义转交、深度、因果顺序、组合路径计数和预算均有测试。相关查询与开发集测试共10项通过。

  --output NEW_PROTOCOL_DIRECTORY
